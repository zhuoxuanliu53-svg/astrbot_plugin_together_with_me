# together with me

群里总会有这种消息：

> 晚上打绝地潜兵，东线难度 7，缺两个人。好友码 1234-5678。

发完过一会儿，它就被聊天顶没了。`together with me` 把这类消息做成一个群内条目：能搜、能看人数，也会在不需要时自己消失。

它不连接任何游戏服务器，也不替你把人拉进游戏。好友码、Steam ID、房间码、服务器地址都只是原样放在条目里；群友看到后自己联系或加入。

## 先试一下

在群里发：

```text
/togethercreate 1234-5678｜绝地潜兵2 / Steam｜备注=东线难度7，拿样本｜初始=2｜上限=4
```

Bot 会回：

```text
[#TW0001] 绝地潜兵2 / Steam
东线难度7，拿样本
2 / 4 人｜短期，至 07-31 21:00
主体：1234-5678
```

群友输入：

```text
/togetherwith #TW0001
```

人数就会变成 `3 / 4`。满员后 Bot 不再接受报名。

## 四条命令

### 建一个条目

```text
/togethercreate <主体文本>｜<游戏或平台>｜备注=<文字>｜初始=<人数>｜上限=<人数或∞>｜长期
```

前两段必填，后面都可以不写：默认没有备注、初始 1 人、人数不限、短期。

```text
# 默认短期；24 小时后自动删除
/togethercreate 1234-5678｜绝地潜兵2

# 已经两个人开了，再找两个人
/togethercreate 1234-5678｜绝地潜兵2｜备注=东线拿样本｜初始=2｜上限=4

# 想长期留在群里，例如 Steam 好友信息
/togethercreate steam:alice｜Steam｜备注=周末一般都在｜长期
```

`|` 和 `｜` 都能用。可选字段可以换顺序，但每种字段只能写一次。

### 找条目

```text
/togetherfind
/togetherfind 绝地潜兵2
/togetherfind 绝地潜兵2｜东线/样本
```

不带内容时列出本群全部可用条目。

- `｜` 表示“同时满足”：`绝地潜兵2｜东线`
- `/` 表示“任选一个”：`东线/南线/样本`

搜索只看“游戏或平台”和“备注”，不会把好友码、ID 之类的主体文本当作搜索词。

### 报名和删除

```text
/togetherwith #TW0001
/togetherdelete #TW0001
```

一个人不能对同一条目重复报名；创建者已经算在初始人数里。条目只允许创建者删除，识别码也只在创建它的群里有效。

## 关于短期和长期

短期条目创建 24 小时后自动删除，适合“今晚开一局”。长期条目不会自动删，适合把明日方舟 ID、Steam 好友方式之类的信息留给群友。

无论哪一种，报名只是本插件里的计数，不代表游戏内已经入队。

## 安装

在 AstrBot 插件市场安装即可；本地开发时，将本目录放进：

```text
AstrBot/data/plugins/astrbot_plugin_together_with_me/
```

然后在 AstrBot WebUI 的插件页面重载。

数据保存在：

```text
AstrBot/data/plugin_data/astrbot_plugin_together_with_me/together_with_me.db
```

Docker 部署时记得持久化 AstrBot 的 `data/` 目录，不然重建容器后条目也会一起没掉。

## 现在没有的功能

- 不能撤销报名；
- 不能编辑已创建的条目；
- 管理员不能越权删除；
- 不验证好友码、ID 或服务器地址是否真的有效。

这些是有意保留的边界：这个插件先把群里“找人一起玩”的信息整理好，别把它做成另一个复杂的社交系统。
