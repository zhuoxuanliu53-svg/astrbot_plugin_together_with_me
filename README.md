# together with me

一个用于群聊内管理游戏联机信息的 AstrBot 插件。

群成员可以创建包含好友码、游戏 ID、房间码、邀请链接或服务器地址的联机条目；其他成员可按游戏名称和备注检索条目，并通过识别码登记报名人数。插件不接入游戏服务器，也不验证主体文本的有效性。

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 短期组队招募 | 适合“今晚开一局”或“还缺两人”的场景；条目默认在 24 小时后自动删除。 |
| 长期加好友 | 可长期保存明日方舟 ID、Steam 好友方式等信息，由创建者手动删除。 |
| 服务器招募 | 可保存服务器地址、房间码或邀请链接，适用于《我的世界》等服务器型游戏。 |
| 群聊隔离 | 条目、报名记录和识别码均按群隔离；其他群无法查询或操作。 |
| 组合搜索 | 支持按游戏/平台和备注搜索；`｜` 表示同时匹配，`/` 表示任一匹配。 |
| 人数登记 | 创建者指定初始人数与人数上限；成员报名后人数自动递增，满员后拒绝新报名。 |
| 持久化 | 数据保存在 AstrBot 插件数据目录，重启 AstrBot 后仍可保留。 |

插件不依赖特定游戏的账号格式。主体文本可使用数字、汉字、字母、空格与常见符号，因此可兼容好友码、玩家 ID、房间码、服务器地址和邀请链接等多种玩法；更多玩法仍可在后续版本中继续扩展。

## 快速开始

### 短期组队招募：绝地潜兵 2

在群聊中创建一个短期条目：

```text
/togethercreate 1234-5678｜绝地潜兵2 / Steam｜备注=东线难度7，拿样本｜初始=2｜上限=4
```

Bot 返回：

```text
[#TW0001] 绝地潜兵2 / Steam
东线难度7，拿样本
2 / 4 人｜短期，至 07-31 21:00
主体：1234-5678
```

其他成员报名：

```text
/togetherwith #TW0001
```

人数会变成 `3 / 4`。满员后 Bot 不再接受报名。

### 长期加好友：明日方舟

```text
/togethercreate JUAN#1234｜明日方舟｜备注=国服，可加好友｜长期
```

该条目默认初始人数为 `1`、人数上限为 `∞`，不会自动删除。

## 命令说明

| 命令 | 用途 |
| --- | --- |
| `/togethercreate` | 创建条目。 |
| `/togetherfind` | 搜索条目；不带参数时列出当前群全部可用条目。 |
| `/togetherwith <识别码>` | 向指定条目报名。 |
| `/togetherdelete <识别码>` | 删除自己创建的条目。 |

### 创建条目

```text
/togethercreate <主体文本>｜<游戏或平台>｜备注=<文本>｜初始=<数字>｜上限=<数字或∞>｜长期
```

前两段为必填项，其余字段可省略，且可选字段顺序不限。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 主体文本 | — | 好友码、玩家 ID、房间码、服务器地址、邀请链接等。支持数字、汉字、字母、空格与常见符号。 |
| 游戏或平台 | — | 用于展示和搜索。 |
| `备注=` | 空 | 自由文本，用于补充玩法、时间、服务器、任务等信息。 |
| `初始=` | `1` | 创建时已经确定的人数。 |
| `上限=` | `∞` | 最大人数；达到上限后不再接受报名。 |
| `长期` | 短期 | 长期条目不自动删除；不写则为 24 小时短期条目。 |

示例：

```text
/togethercreate 1234-5678｜绝地潜兵2
/togethercreate MC.example.com:25565｜我的世界｜备注=Java 1.21 生存服｜初始=3｜上限=8
/togethercreate steam:alice｜Steam｜备注=周末一般都在｜长期
```

`|` 与 `｜` 均可作为字段分隔符，因此主体文本、游戏或平台和备注中不能直接使用这两个字符。每个可选字段只能出现一次。

## 搜索规则

搜索仅匹配“游戏或平台”和“备注”，不会匹配主体文本。

```text
/togetherfind 绝地潜兵2｜东线/南线/样本
```

- `｜`：不同条件同时满足；
- `/`：同一条件中的任一关键词匹配；
- 不带搜索参数：列出当前群全部未过期条目。

## 数据与行为

- 识别码仅在创建它的群内有效；
- 创建者已计入初始人数，不能再次报名；
- 同一成员不能重复报名同一条目；
- 报名仅记录群内意向和人数，不表示已在游戏内成功加入；
- 条目仅允许创建者删除；
- 短期条目在创建后 24 小时自动清理；长期条目不会自动清理。

数据库文件位于：

```text
AstrBot/data/plugin_data/astrbot_plugin_together_with_me/together_with_me.db
```

Docker 部署时，请持久化 AstrBot 的 `data/` 目录，否则容器重建后条目与报名记录会丢失。

## 安装

将插件目录放入：

```text
AstrBot/data/plugins/astrbot_plugin_together_with_me/
```

然后在 AstrBot WebUI 的插件页面重载插件。插件依赖由 `requirements.txt` 声明。

## 当前限制与后续方向

当前版本不支持撤销报名、编辑已创建条目、管理员越权删除，也不校验主体文本的真实性与可用性。

插件当前专注于提供一套兼容性高、适用于不同游戏和不同群聊习惯的基础联机信息机制。围绕审核、通知、报名管理、更多搜索方式和其他玩法的扩展，将在后续版本中逐步开发。
